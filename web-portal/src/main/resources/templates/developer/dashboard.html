Base URL http://localhost:8081

Endpoint reference

  • POST
    /api/v1/merchants

    Onboard a merchant and run KYC against the sandbox.

  • GET
    /api/v1/merchants/{id}

    Fetch a merchant by id.

  • POST
    /api/v1/merchants/{id}/kyc

    Re-run KYC verification for a merchant.

  • POST
    /api/v1/payments

    Create a payment in CREATED status for a KYC-verified merchant.

  • POST
    /api/v1/payments/{id}/pay

    Run the risk check and authorize with card details.

  • POST
    /api/v1/payments/{id}/capture

    Capture an authorized payment and post it to the ledger.

  • GET
    /api/v1/payments/{id}

    Fetch a payment by id.

  • GET
    /api/v1/payments?merchantId={id}

    List payments, optionally filtered by merchant.

Sandbox

Test cards

Card number Outcome
4111111111111111 APPROVE
4000000000000002 DECLINE

Use any future expiry date and any 3-digit CVV. Card numbers must pass the Luhn check.

Partner rules

  • Bank payout

    A payout to an account number ending in 0000 fails. Any other account succeeds and returns a UTR-style reference.

  • KYC verification

    A business name containing reject is rejected. Any other name is verified.
